# Монгол аялал — маршрут төлөвлөгч

21 аймгийн аяллын маршрут, өдөр бүрийн хөтөлбөр гаргадаг сайт. Хэрэглэгчийн бүртгэл, үнэгүй ба премиум хэсэгтэй.

## Файлууд

| Файл | Юу хийдэг |
|---|---|
| `index.html` | Сайтын бүтэц |
| `style.css` | Загвар |
| `app.js` | 21 аймгийн мэдээлэл, маршрут, хөтөлбөр, paywall |
| `auth.js` | Нэвтрэх, премиум шалгах, аялал хадгалах (Supabase) |
| `config.js` | **Таны тохиргоо** — Supabase түлхүүр, үнэ |
| `supabase/schema.sql` | Мэдээллийн сангийн хүснэгтүүд |

## Юу үнэгүй, юу премиум

- **Үнэгүй:** аймаг сонгох, газрын зураг, маршрут ба зардал, хөтөлбөрийн 1-р өдөр, аймгийн бүх мэдээлэл, яаралтай тусламж.
- **Премиум:** бүтэн хөтөлбөр, аялал хадгалах (Миний аяллууд), хөтөлбөр хуулах.

---

## 1-р алхам: Supabase тохируулах (~15 мин)

1. https://supabase.com → **Start your project** → GitHub эсвэл Google-ээр бүртгүүлнэ.
2. **New project**: нэр `campsite`, Region-оос **Southeast Asia (Singapore)** сонгоно (Монголд хамгийн ойр). Database password-оо хадгалж аваарай.
3. Зүүн цэс → **SQL Editor** → **New query** → `supabase/schema.sql` файлын бүх агуулгыг хуулж буулгаад **Run** дарна.
4. **Project Settings → API** хэсгээс:
   - `Project URL` → `config.js`-ийн `SUPABASE_URL`
   - `anon public` key → `config.js`-ийн `SUPABASE_ANON_KEY`
   - ⚠️ `service_role` түлхүүрийг сайтын код руу хэзээ ч бүү хуул.

## 2-р алхам: Нэвтрэх аргууд

**Имэйлээр (заавал биш, анхнаасаа ажилладаг):** Authentication → Providers → Email асаалттай байгаа эсэхийг шалга.

**Google-ээр (зөвлөнө):**
1. https://console.cloud.google.com → шинэ project → **APIs & Services → OAuth consent screen** бөглөнө.
2. **Credentials → Create credentials → OAuth client ID → Web application**.
3. *Authorized redirect URIs* хэсэгт Supabase-ийн өгсөн хаягийг оруулна (Supabase → Authentication → Providers → Google дотор харагдана: `https://<таны-төсөл>.supabase.co/auth/v1/callback`).
4. Гарсан Client ID, Client Secret-ийг Supabase → Providers → Google-д оруулж Save.

**Чухал:** Authentication → **URL Configuration**:
- *Site URL*: сайтын үндсэн хаяг (жишээ нь `https://campsite.vercel.app`)
- *Redirect URLs*: дээрх хаяг + `http://localhost:5500` (өөрийн компьютер дээр турших бол)

## 3-р алхам: Өөрийн компьютер дээр турших

```bash
cd campsite
npx serve -l 5500 .
```
эсвэл VS Code-ийн **Live Server** өргөтгөлөөр `index.html`-ийг нээнэ. Файлыг шууд давхар дарж нээвэл нэвтрэх хэсэг ажиллахгүй.

## 4-р алхам: Интернэтэд байршуулах (Vercel, үнэгүй)

1. GitHub дээр шинэ repository үүсгээд энэ хавтсыг push хийнэ.
2. https://vercel.com → GitHub-ээр нэвтэрнэ → **Add New → Project** → repository-оо сонгоно.
3. Framework Preset: **Other**, Build command хоосон → **Deploy**.
4. Гарсан хаягаа (`xxx.vercel.app`) Supabase-ийн URL Configuration-д нэмнэ.
5. Өөрийн домэйн (`.mn`) байвал Vercel → Settings → Domains хэсэгт холбоно.

## 5-р алхам: Премиумыг турших

1. Сайт дээр нэвтэрнэ.
2. Supabase → SQL Editor дээр:
   ```sql
   update public.profiles set premium_until = now() + interval '30 days'
   where email = 'таны@имэйл.mn';
   ```
3. Сайт дээр «Төлбөр төлсөн бол — эрхээ шалгах» дарах эсвэл хуудсаа refresh хийнэ. ★ Премиум тэмдэг гарч бүтэн хөтөлбөр нээгдэнэ.

QPay холбогдох хүртэл төлбөрийг гараар (дансаар) авч, дээрх SQL-ээр эрх нээж болно.

---

## Аюулгүй байдлын тэмдэглэл

- `premium_until`-ийг хэрэглэгч өөрөө өөрчилж чадахгүй (RLS). Зөвхөн та SQL-ээр эсвэл дараа нь төлбөрийн сервер өөрчилнө.
- Аялал хадгалах эрхийг мэдээллийн сан өөрөө шалгадаг тул премиумгүй хүн хуурч хадгалж чадахгүй.
- Харин өдөр бүрийн хөтөлбөр хөтөч дээр тооцоологддог тул програмчлал мэддэг хүн нээж харж болно. Үүнийг 3-р алхамд шийднэ: үнэтэй мэдээллийг (кемпийн үнэ, утас, шалгасан мэдээлэл) мэдээллийн санд хадгалж, зөвхөн премиум хэрэглэгчид өгнө.

## 2-р алхам: Дансаар / QR-ээр төлөх + админ хуудас

1. Supabase → SQL Editor → `supabase/02_payments.sql`-ийг бүтнээр нь ажиллуулна.
2. Сайтад нэг удаа нэвтэрсний дараа өөрийгөө админ болгоно:
   ```sql
   insert into public.admins (user_id) select id from auth.users where email = 'таны@имэйл';
   ```
3. `config.js` дотор `BANK_NAME`, `BANK_ACCOUNT`, `BANK_HOLDER`, `CONTACT`-ийг бөглөнө.
4. (Заавал биш) Банкны апп-ын «Миний QR» зургийг `qr.png` нэрээр репод оруулж, `BANK_QR_IMAGE: 'qr.png'` болгоно.
5. Админ хуудас: `https://<таны-сайт>/admin.html`

**Ажиллах дараалал:** хэрэглэгч Премиум → данс/QR руу шилжүүлж, гүйлгээний утгад `CS-XXXXXX` код бичнэ → «Төлсөн — шалгуулах» → та админ хуудаснаас дансны хуулгатай тулгаад **✓ Батлах** → эрх автоматаар нээгдэнэ.

## 3-р алхам: Санал хүсэлт
Supabase → SQL Editor → `supabase/03_feedback.sql`. Хэрэглэгчийн илгээсэн саналууд админ хуудасны «💬 Санал хүсэлт» табд харагдана.

## 4-р алхам: 1 өдрийн үнэгүй туршилт
Supabase → SQL Editor → `supabase/04_trial.sql`. Хэрэглэгч бүр нэг удаа «🎁 1 өдөр үнэгүй турших» товчоор 24 цагийн премиум авна.

## 5-р алхам: Шатахууны үнэ, айл буудал
Supabase → SQL Editor → `supabase/05_fuel_homestay.sql`. Шатахууны үнийг админ хуудасны «⛽ Шатахууны үнэ» табаас шинэчилнэ; айл буудлын саналуудыг «🐎 Айл буудал» табаас нийтэлнэ. Цаг агаар (Open-Meteo), «Би энд байна», газрын домог нь `features.js`-д.
